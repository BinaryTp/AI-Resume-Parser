# 📌 Overview

AI Resume Parser is a modern web application that automatically extracts important information from resumes using **Google Gemini AI**.

Instead of relying only on regular expressions, the application uses Large Language Models (LLMs) to understand resume content and generate structured outputs such as:

- Candidate Information
- Skills
- Education
- Projects
- Certifications
- Professional Summary
- ATS Resume Score
- AI Suggestions

# ⚙ Installation

Clone the repository

```bash
git clone https://github.com/BinaryTp/AI-Resume-Parser.git
```

Move into the project

```bash
cd AI-Resume-Parser
```

Create virtual environment

```bash
python -m venv venv
```

Activate environment

Windows

```bash
venv\Scripts\activate
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
streamlit run app.py
```
